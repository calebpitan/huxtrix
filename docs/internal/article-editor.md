# Article editor

## Purpose

`/create` and `/create/publish` share one in-memory draft. The header on `/create` switches that draft between an article and a short post, shows how long the article is, and previews it in the same column.

## Implementation

[`TextEditorProvider`](../../apps/www/src/compositions/editor/TextEditorProvider.tsx) lives on [`create/layout.tsx`](../../apps/www/src/app/create/layout.tsx) and wraps [`CreatePlateController`](../../apps/www/src/app/create/plate-controller.tsx), so both routes see the same draft, edit/preview mode, and saved snapshot, and the sidebar can read the article editor. A refresh clears them. [`creator.tsx`](../../apps/www/src/app/create/creator.tsx) registers `controller.save()` and `controller.post()`; both log the current body.

`draft.body` is the serialized Plate value. An editor with no text stores `''`. Title and subtitle are `draft.title` and `draft.subtitle`. `channelId` is the category name from the writing-column menu, or null. `coverUrl` is a session object URL, or null.

[`creator.tsx`](../../apps/www/src/app/create/creator.tsx) puts the header and the article editor in one `max-w-4xl` column. [`ArticleEditor.tsx`](../../apps/www/src/compositions/editor/ArticleEditor.tsx) lays the channel chip, the cover chip, the title, the subtitle, and the body inside it. From `lg`, that writing is inset `px-28`. [`ChannelChip`](../../apps/www/src/compositions/editor/channel-chip.tsx) and [`CoverChip`](../../apps/www/src/compositions/editor/cover-chip.tsx) render while editing. Preview hides them and keeps the title, subtitle, and body on that same left edge. The body is [`PlainEditor`](../../apps/www/src/compositions/editor/PlainEditor.tsx) with `variant="none"`, so the editor's centering padding is not applied. `ps-6` stays on the editor as the gutter for the existing drag handle. From `lg` the editor shifts back by that same 24px so the text still lines up with the title.

[`PlainEditorToolbar`](../../apps/www/src/compositions/editor/PlainEditor.tsx) is the same Radix toolbar as before, drawn as a capsule. From `lg` the row is `px-8` and the capsule is `w-full`, with its groups spread so the last control sits at the right end. It renders only while `type` is `article` and `mode` is not `preview`. The row is a direct child of the article column, `sticky` at `--create-header-height`, which [`CreateHeader`](../../apps/www/src/app/create/create-header.tsx) writes onto their shared parent. The old 40px grid row is gone: a sticky box cannot leave its parent, and that row was only the toolbar tall.

[`CreateHeader`](../../apps/www/src/app/create/create-header.tsx) is rendered from `creator.tsx`, so it exists on `/create` only, from the `lg` breakpoint up. It composes [`DraftTypeToggle`](../../apps/www/src/app/create/draft-type-toggle.tsx), [`DraftStatus`](../../apps/www/src/app/create/draft-status.tsx), [`PreviewButton`](../../apps/www/src/app/create/preview-button.tsx), [`SaveDraftButton`](../../apps/www/src/app/create/save-draft-button.tsx), and [`CreatePrimaryButton`](../../apps/www/src/app/create/create-primary-button.tsx). Below that, [`@appbar/page.tsx`](../../apps/www/src/app/create/@appbar/page.tsx) keeps Cancel and one primary button. On `/create` that button is Next or Post, matching `draft.type`. On `/create/publish` the button stays Next and calls `controller.post()`.

[`@sidebar/page.tsx`](../../apps/www/src/app/create/@sidebar/page.tsx) renders the article context panel while `draft.type` is `article`. A short post renders nothing in that slot. [`@sidebar/default.tsx`](../../apps/www/src/app/create/@sidebar/default.tsx) renders nothing, so `/create/publish` does not show this panel. The panel is `sticky top-0` inside the existing aside. On create that aside’s first child is `w-100`. Other pages keep `w-64`. It stays hidden below `xl`.

The panel is [`article-context/panel.tsx`](../../apps/www/src/app/create/article-context/panel.tsx). It stacks Posting to, channel guidelines, the outline, and drafts. [`ChannelMenu`](../../apps/www/src/compositions/editor/channel-menu.tsx) is the same popover the writing-column chip opens. Change is a second trigger and sets `channelId`. The posting row shows the channel icon, name, and member string. Maths & Science omits the count. Joined is a static label. Guidelines render only after a channel is chosen. Tech uses three fixed lines. Every other channel uses one shared placeholder. The outline reads top-level `h1`, `h2`, and `h3` nodes from the article editor. Drafts is the heading and “No drafts yet”.

[`draft-text.ts`](../../apps/www/src/compositions/editor/draft-text.ts) turns the title, subtitle, and Plate body into a word count and the status string. Preview passes `readOnly` to Plate, hides [`PlainEditorToolbar`](../../apps/www/src/compositions/editor/PlainEditor.tsx), and renders the title and subtitle as text. [`ArticleEditor.tsx`](../../apps/www/src/compositions/editor/ArticleEditor.tsx) only does that while `type` is `article`.

[`ConfirmPostDialog`](../../apps/www/src/app/create/confirm-post-dialog.tsx) is the `AppDialog` the header and the phone bar both open before `controller.post()`.

[`CreateNavigationGuard`](../../apps/www/src/app/create/navigation-guard.tsx) uses `useNavigationGuard` from `next-navigation-guard`. It blocks leaving create while `draft.body` is non-empty. Routes under `/create` stay inside the draft, so `/create/publish` does not ask. [`NavigationGuardProvider`](../../apps/www/src/compositions/layout/Root.tsx) owns the interception.

## Decisions

- **Saved is a snapshot on the provider.** `markSaved()` copies the draft after `controller.save()`. The header shows Saved while the live draft still matches that copy, so a write of the same body keeps the marker, and a trip to `/create/publish` keeps it too. Any real field change drops it. Nothing is written to storage.
- **Words come from plain text.** Title, subtitle, and the text nodes in the Plate body are joined, then split on whitespace. Adjacent blocks are separated so two paragraphs stay separate words. Read time is `max(1, round(words / 200))` once there is a word, and omitted at zero.
- **Preview stays on `/create`.** The same column is read-only, and the button label switches to Edit. Choosing Post while previewing returns the column to edit, because the Post header has no Preview control.
- **Article Next opens `/create/publish`.** The navigation guard already treats that path as staying inside create, so the draft remains and the unsaved-changes dialog stays closed. `controller.post()` belongs to the Post button.
- **The guard package is `next-navigation-guard` 0.2.** 0.1.2 only wrapped `router.push`. Next.js 15.3 `Link` no longer navigates that way, so those clicks left create without asking. 0.2 intercepts them in the provider. The create page only decides when the guard is enabled. The 0.1.2 `crypto.randomUUID` patch is gone; 0.2 already uses `Math.random` for history tokens.
- **Post confirms first.** Confirm calls `controller.post()` and stays on `/create`. Cancel leaves the draft in place.
- **Title and subtitle are draft fields.** The status line and the preview both read them.
- **One column lines the header, the pill, and the writing up.** They share `max-w-4xl`. From `lg` the header controls sit on the column edges, the pill is inset `px-8` (32px), and the writing is inset `px-28` (112px). Chips, title, subtitle, and the first body line share that inner edge. The drag handle still sits `absolute` and fully to the left of each block, inside an editor that clips overflow on x, so the editor keeps a 24px `ps-6` gutter and shifts left by the same amount from `lg`. Below `lg` the writing keeps the smaller padding. The old split between `max-w-3xl` and `max-w-[896px]` is gone.
- **The slash hint is two placeholders with one sentence.** On an empty body, Plate’s editor placeholder is the only hint, so that prop carries “Type / to insert a heading, image, code block…”. The block placeholder uses the same sentence, and Plate only shows it on an empty paragraph once the body already has text and that paragraph is focused. Typing `/` still opens `SlashKit`.
- **Code block chrome shares the panel grid.** The language control and the copy button occupy the same cell as the code, aligned to the top end. Safari drops `top` on an absolutely positioned control inside the editable and paints those controls under the panel. The overlay ignores pointer events except on the two controls.
- **`channelId` is the category name.** The combobox copies the six home-category member strings and adds Maths & Science as `115k members`. That count is a menu label, not a membership record. An empty search shows the first twenty in that written order, which stands in for frequently used, because nothing records access. A search filters the whole list, so a name past those twenty can still be chosen. It is not a membership catalog, and it does not import the home page.
- **The channel and cover chips are 40px.** Both triggers are `Button` `size="lg"` (`h-10`) with `rounded-full`. Their fill is transparent, so the page color shows through the border. The outline variant’s dark fill is a tint, and the article screen does not use it. The empty cover chip stays dashed. The remove control stays a ghost icon button.
- **The cover is a session object URL.** Choosing a file stores `URL.createObjectURL` on `coverUrl`. Nothing is uploaded. Replace and clear revoke the previous `blob:` URL. Unmount does not: preview remounts the editor while the draft still holds the URL. A refresh drops it with the rest of the draft.
- **Header chrome uses `Button`.** The mode control is a local inset track, because shadcn Toggle Group is a row of separate buttons and Radio Group is a circle list. The track is `bg-muted/40` with a 1px border and 4px of padding, lighter than a solid muted fill. The active option is `variant="default"` `size="lg"` (40px). The inactive option is `variant="ghost"`. The border sits outside that padding, so the track is 50px tall. Preview, Edit, and Save draft are `variant="ghost"` at 44px (`h-11`), with an eye only on Preview. Save draft has no resting fill; the ghost variant supplies the hover fill. Next and Post are `variant="default"` at that same 44px, and Next has a trailing arrow.
- **The format pill is 50px, and the header sticks with it.** Each control is `ToolbarButton` `size="default"` (36px), one step under the 40px Article segment. Icons stay 16px, the same size as the eye on Preview. The capsule is `px-2.5 py-1.5` and a 1px border, so `6 + 36 + 6 + 2 = 50`. Its fill is `bg-muted/30`, a light wash on the page color. Groups use a 2px gap, and `justify-between` spreads those groups across the capsule. The rules are 20px tall with 8px on either side. Outdent comes before indent. The mode track is 50px, so the 44px header buttons sit 11px above the header’s bottom edge, and the toolbar row adds `pt-3.5` (14px) inside the sticky band. That leaves 25px between those buttons and the pill while the page scrolls. The header is `sticky` at the top of the window with `bg-background`, and it publishes its height so the pill sticks against its bottom on the wide layout, where the window scrolls. Below `xl` the editor column scrolls and the pill already sits outside that scroller. Preview and Post omit the row. The shared button variants are unchanged.
- **The title is one step larger than the body.** Title is `text-5xl font-extrabold tracking-tighter`. Subtitle stays `text-lg` and uses `font-medium` at 70% foreground, so it sits between the title and the body.
- **The outline reads the primary editor.** Plate only hands a sibling the unfocused editor when that editor is `primary`, so the article `Plate` sets `primary`. The outline subscribes to the value and selection versions. Plate’s tracked value and selection selectors read `editor.children` before that editor exists and throw. The heading list debounces the value version by 200ms, then reads `editor.children`. The active row does not wait. It is the last top-level heading whose block index is less than or equal to the caret’s block, which keeps the heading active through the section under it. A path-prefix check would light the row only while the caret sits inside the heading itself. Clicking a row selects the start of that heading and scrolls that heading into view, just below the sticky header and toolbar. `scrollIntoView` is not used. The editor sets `overflow-x: hidden`, so its vertical overflow computes to `auto`, and `scrollIntoView` scrolls that box. The box is as tall as its text, so the page does not move. The click scrolls the ancestor that can actually scroll, or the window when none can. Preview keeps the panel. The editor is read-only there, and the same select still moves the caret.
- **Change shares the chip’s menu.** One list supplies both triggers, including the `115k members` label on Maths & Science. The posting row hides that count. Joined does not send a request. Guidelines are placeholder copy, hidden until a channel is selected.
- **The create aside is wider than the home one.** The shared layout still defaults the right-hand slot to `w-64`. Create passes `contextClassName` so the article panel is `w-100` (400px). The writing column already shrinks, and the home channel list stays at the default width.
- **The panel uses the article frame’s colors.** Change is `text-cyan-600` and `dark:text-cyan-300` (`#67e8f9` on the dark frame). The link variant keeps the hover underline and adds no resting fill. The check is `text-emerald-400` (`#34d399`). The pill border is `border-primary`, which is `#e4e4e7` in dark mode, with no fill. The channel mark is 48px at `bg-foreground/10`. The guidelines block is `rounded-2xl bg-muted/30`, a lighter wash than the code block’s `bg-muted/50`, not the bordered card. Outline rows are ghost buttons. A straight `w-0.5` rail sits flush with the heading. It is `bg-foreground/15` for the list, and the active row covers its own segment with `bg-foreground`. A left border is not used: the ghost button is `rounded-md`, so `border-l` bends into a curve. Section labels are `text-sm` and sit flush left. The stack is 16px under the label, 20px before the card, then 40px before Outline and before Drafts.

## Limits

There is no autosave, `localStorage`, or network save. The cover is not uploaded. The short-post composer is not in the column, and Post does not show the format pill. `/create/publish` is a placeholder heading and does not show this panel. Drafts are not queried or listed. Channel guidelines and Joined are not membership records. The panel is hidden below `xl`, and there is no bottom sheet. The phone bar has Cancel and Next, or Cancel and Post, and leaves out the mode choice, the word count, Preview, and Save draft. The format pill does not dock above the keyboard.
